# 2026-08-26-ligaBit

Programa em C para microcontrolador AVR (ATmega328P, 16 MHz), feito no Microchip Studio.

Primeira versão com macros de manipulação de bits (`lerBit` e `ligaBit`). A `ligaBit` configura PB1 como saída no `DDRB`, e o programa liga o LED em PB1 conforme o estado do botão em PB0.
