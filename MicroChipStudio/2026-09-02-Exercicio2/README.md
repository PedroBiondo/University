# 2026-09-02-Exercicio2

Programa em C para microcontrolador AVR (ATmega328P, 16 MHz), feito no Microchip Studio.

Estende o exercício 1 usando os dois canais do Timer0: PD6 (OC0A) com duty cycle variável e PD5 (OC0B) com duty fixo (`OCR0B = 150`). O LED em PB1 continua sendo invertido a cada 1 segundo.
